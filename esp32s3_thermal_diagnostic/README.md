# ESP32-S3 发热隔离测试

先完全断开 DRV8833、L298N、电机电源和所有电机控制杜邦线，只保留 USB 连接 ESP32-S3。烧录 `esp32s3_thermal_diagnostic.ino`，打开 115200 波特率串口监视器。

## 固定测试步骤

1. 程序启动即为 **A 阶段：Wi-Fi 关闭，未配置任何电机 GPIO**。从上电开始计时 2 分钟，记录芯片温度感受：凉、微温、温热、烫手。
2. 串口发送小写 `w`，进入 **B 阶段：仅开启 Wi-Fi 热点**，不连接手机也不运行网页。从切换开始计时 2 分钟，再记录温度。
3. 串口发送 `i` 可关闭 Wi-Fi；`s` 显示当前状态和剩余堆内存。

## 判定

- A 阶段已经烫手：与 Wi-Fi、DRV8833 和本项目程序无关；开发板/芯片可能已损伤，停止通电。
- A 阶段正常、B 阶段只是微温或温热：Wi-Fi 无线电的正常功耗，不是故障。
- A 阶段正常、B 阶段烫手：板子的 Wi-Fi/供电部分可能损伤；停止通电。

若芯片在任何阶段出现短时间明显烫手、焦味、自动重启或 USB 断连，立即拔掉 USB，不再进行后续阶段。
