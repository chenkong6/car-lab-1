# ESP32-S3 双 L298N、四电机本地循环测试

程序不启用 Wi-Fi。上电后永久执行：四个电机前转 2 秒 → 滑行停 1 秒 → 四个电机反转 2 秒 → 滑行停 1 秒。

## 接线

每块 L298N 的 `ENA`、`ENB` 跳帽都必须拔掉，ESP32-S3、两块 L298N 和电机电源必须共地。

| L298N | 通道 | 引脚 | ESP32-S3 GPIO |
| --- | --- | --- | --- |
| #1 | 电机 1 | IN1 / IN2 / ENA | 4 / 5 / 7 |
| #1 | 电机 2 | IN3 / IN4 / ENB | 8 / 9 / 10 |
| #2 | 电机 3 | IN1 / IN2 / ENA | 11 / 12 / 13 |
| #2 | 电机 4 | IN3 / IN4 / ENB | 14 / 15 / 16 |

程序刻意避开 GPIO0、GPIO6、GPIO19/20 和 GPIO26–32。GPIO6 是旧板确认损坏的引脚，新旧板均不使用。

## 若四台电机只蜂鸣、不转

烧录独立草图目录 `../esp32s3_4motor_l298n_sequential_diagnostic/esp32s3_4motor_l298n_sequential_diagnostic.ino`。它每次只测试一台电机的正反转，排除四台同时起动造成的电源掉压。

- 单台能转、四台同时不能转：电机电源瞬时电流不足；使用电流能力更大的约 6V 电源，并在每块 L298N 的电机电源端就近加电容。
- 单台也只蜂鸣：先将 `TEST_PWM` 从 `102`（40%）升至 `153`（60%）；若仍不转，检查 ENA/ENB 跳帽是否已拔、L298N 逻辑 5V 与所有 GND 是否正确。

## 使用与安全

1. Arduino IDE 选择 `ESP32S3 Dev Module`，烧录 `esp32s3_4motor_l298n_cycle_test.ino`。
2. 第一次测试将车架空，打开 115200 波特率串口监视器。
3. 默认 PWM 为 40%（`TEST_PWM = 102`）。确认电机方向无误后才提高占空比。

若某一轮与其他轮方向相反，交换该电机接到 L298N 输出端的两根线。额定 6V TT 电机使用约 6V 电机电源；不要长期直接接 12V。
