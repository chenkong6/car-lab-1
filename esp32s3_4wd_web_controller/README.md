# ESP32-S3 双 L298N、四 TT 电机 Wi-Fi 热点控制

此程序让 ESP32-S3 建立独立 Wi-Fi 热点，手机连接后访问控制页，统一控制四个 TT 电机的方向与 PWM 档位。默认 PWM 为 40%，可选 20%、40%、60%、80%。

## 接线

两块 L298N 的 `GND`、ESP32-S3 `GND`、电源负极必须共地。每块 L298N 都必须拔掉 `ENA`、`ENB` 跳帽，否则 ESP32 的 PWM 调速无效。

为避免 ESP32-S3 上电、复位或烧录期间 GPIO 还是输入态时误转，建议在**每个** L298N 的 `ENA`、`ENB` 与 `GND` 之间各接一个 **10 kΩ 下拉电阻**（共四个）。程序上电时也会先把四路使能关闭；下拉电阻负责保护软件尚未启动的那一小段时间。

| 模块 | 电机通道 | L298N 引脚 | ESP32-S3 GPIO |
| --- | --- | --- | --- |
| L298N #1 | 左前 | IN1 / IN2 / ENA | GPIO4 / GPIO5 / GPIO6 |
| L298N #1 | 左后 | IN3 / IN4 / ENB | GPIO7 / GPIO8 / GPIO9 |
| L298N #2 | 右前 | IN1 / IN2 / ENA | GPIO10 / GPIO11 / GPIO12 |
| L298N #2 | 右后 | IN3 / IN4 / ENB | GPIO13 / GPIO14 / GPIO15 |

若某一只电机方向与其余三只相反，请交换该电机接在 L298N 输出端的两根线；不要改全局方向逻辑。

## 供电安全

额定 6V 的 TT 电机不可长期直接接 12V。推荐用 DC-DC 将电机电源降至 6V 后接入每块 L298N 的电机电源端。ESP32-S3 继续由 USB 或独立稳压供电。

L298N 压降较大，若四个电机动力不足，建议之后更换为 TB6612FNG 或 DRV8833 驱动器。

## 使用

1. Arduino IDE 选择 `ESP32S3 Dev Module`，打开并烧录 `esp32s3_4wd_web_controller.ino`。
2. 手机连接热点：`ESP32_4WD_Motor`，密码：`motor1234`。
3. 浏览器打开 `http://192.168.4.1`。
4. 选择 PWM 档位，再点击“全部正转”或“全部反转”。点击“零值刹车”立即动态刹车。

页面在运动期间每 250 ms 发送保活信号。手机断开热点、关闭网页或 Wi-Fi 失联超过约 1.2 秒，ESP32 自动进入零值刹车。

## 若上电就有一只电机全速转

这不是正常现象。先断开电机电源，按以下顺序检查：

1. 故障所在 L298N 的 `ENA`、`ENB` 跳帽是否都已经拔掉；跳帽保留时该路永久使能，PWM 线不起作用。
2. 对照上表确认该电机所属通道的 `IN1/IN2/EN` 三根线没有错位，尤其不能把 `EN` 接到 `5V` 或另一个 `IN`。
3. 为每一个 `ENA/ENB` 加 10 kΩ 到 GND 的下拉电阻后重新上电。
4. 若拔掉该路的 `EN` 杜邦线便停止，说明问题集中在 EN 路（跳帽、误接或悬空），而不是 TT 电机本身。

烧录本程序后，等待串口打印热点信息至少 3 秒；此时未点网页按钮，四路电机都应保持不转。若仍有一只持续全速转，拍清楚该 L298N 的 ENA/ENB 跳帽和三根控制线的位置，再继续排查。

GPIO19/20 是 ESP32-S3 的原生 USB 引脚，GPIO26-32 是 Flash/PSRAM 专用引脚，本项目未使用它们。
