CubeMX：STM32F103C8T6 两轮差速小车

成果：生成一个 Keil 工程，PA0/PA3 输出 PWM，PA1/PA2/PA4/PA5 控制 L298N 方向。

1. 新建芯片工程

打开 STM32CubeMX → New Project → MCU/MPU Selector，搜索并选择 STM32F103C8Tx。

2. System Core

System Core → SYS：Debug 设为 Serial Wire，保留 PA13/PA14 给 ST-Link。

3. 分配引脚

功能引脚L298N
TIM2 PWM CH1PA0ENA
GPIO_OutputPA1 / PA2IN1 / IN2
TIM2 PWM CH4PA3ENB
GPIO_OutputPA4 / PA5IN3 / IN4

PA6、PA7 不使用；L298N 的 ENA/ENB 跳帽必须拔掉。

4. 配置时钟

System Core → RCC：HSE 设为 Crystal/Ceramic Resonator。Clock Configuration：SYSCLK 配为 72 MHz（HSE 8 MHz、PLL ×9），APB1 Prescaler 保持 /2。

5. 配置 TIM2 PWM

Prescaler: 71
Counter Period: 999
CH1 Pulse: 0
CH4 Pulse: 0

这是约 1 kHz PWM；程序运行时再设为 40% 占空比。

6. 生成 Keil 工程

Project Manager：Project Name 填 l298n_auto_car；Toolchain / IDE 选 MDK-ARM；Code Generator 勾选 Keep User Code when re-generating；点击 GENERATE CODE。

接线安全

STM32 GND、L298N GND 与电机电源负极必须共地。TT 电机使用约 6V；不要长期直接接 12V。

检查题

不看上文：哪两个引脚输出 PWM？答案是 PA0（CH1）和 PA3（CH4）。完成后把 CubeMX 的 Pinout & Configuration 截图发来，再加入固定循环逻辑。
