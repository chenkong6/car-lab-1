# ESP32-S3 + DRV8833 双 TT 电机 Wi-Fi 控制

程序创建热点并提供手机网页控制。默认 PWM 为 40%，可选 20%、40%、60%、80%；可统一控制两个轮子正转、反转和动态刹车。

## 接线

| DRV8833 引脚 | ESP32-S3 |
| --- | --- |
| IN1 / AIN1 | GPIO4 |
| IN2 / AIN2 | GPIO5 |
| IN3 / BIN1 | GPIO10 |
| IN4 / BIN2 | GPIO7 |
| SLP / nSLEEP | GPIO8 |
| GND | ESP32 GND，且与电机电源负极共地 |

`OUT1/OUT2` 接左轮 TT 电机，`OUT3/OUT4` 接右轮 TT 电机。某一个轮子方向相反时，只交换该电机在 OUT 端的两根线。GPIO6 已确认损坏，本项目及后续接线均不使用它。

模块标为 `VCC` 的脚通常是电机电源输入：为 6V TT 电机提供约 6V，**不要直接接 12V**。ESP32-S3 由 USB 或单独的稳压电源供电。

`SLP` 必须接到 GPIO8，不能悬空。建议在 `SLP` 和 GND 间加 10kΩ 下拉电阻，这样 ESP32 上电或复位前驱动器默认睡眠，不会误转。

本程序中 **FLT/nFAULT 不连接 ESP32，直接悬空**。它是开漏故障输出，部分模块可能把它上拉到模块的 `VCC`（电机电压）。如果该 VCC 为 6V，再接到 ESP32 GPIO 会造成 6V 反向灌入 GPIO，可能导致发热或损坏。

## 使用

1. Arduino IDE 选择 `ESP32S3 Dev Module`，烧录 `esp32s3_drv8833_2wd_web_controller.ino`。
2. 手机连接热点 `ESP32_DRV8833_2WD`，密码 `motor1234`。
3. 打开 `http://192.168.4.1`。

初始状态为驱动器睡眠、两轮不转。点击正转、反转或刹车后，程序拉高 `SLP`，再控制桥臂。运行时网页发送保活；超时约 1.2 秒自动动态刹车。

## 发热或停止后反转的处理

烧录本版程序前，先断电并断开 `FLT/nFAULT` 到 ESP32 的任何杜邦线。新版会在每次切换方向、停止和刹车时，先解除旧 PWM 输出，再写入新的数字电平，防止旧 PWM 残留造成反向转动。

若 ESP32 仍异常发热，立刻断电，不要继续测试；确认 ESP32 没有接到超过 3.3V 的任何信号，DRV8833 的 `VCC` 只接电机电源，ESP32 仅接 GND、四个 IN 和 SLP。电机电源入口靠近 DRV8833 模块处建议并联 100uF 以上电解电容和 0.1uF 陶瓷电容（接 VCC 与 GND，不是接在电机两端）。
