# ESP32-S3 + L298N 两轮差速、前万向轮小车

这是两轮差速小车，不是全向麦克纳姆底盘：两个后轮由 L298N 独立驱动，前部万向轮仅负责支撑。程序提供前进、后退、原地左旋、原地右旋、零值刹车和 PWM 档位控制。

## 接线

先拔掉 L298N 的 `ENA`、`ENB` 跳帽；否则 PWM 调速无效。ESP32、L298N 与电机电源负极必须共地。

| L298N | ESP32-S3 |
| --- | --- |
| 左后轮 IN1 | GPIO15 |
| 左后轮 IN2 | GPIO2 |
| 左后轮 ENA | GPIO4 |
| 右后轮 IN3 | GPIO16 |
| 右后轮 IN4 | GPIO17 |
| 右后轮 ENB | GPIO5 |
| GND | ESP32 GND 与电源负极 |

GPIO6 已损坏，本程序不使用。GPIO18 留作备用；GPIO0 是启动配置脚、GPIO19 是 ESP32-S3 原生 USB 引脚，均不接 L298N 控制线。L298N 的电机电源应为适合 TT 电机的约 6V，不能长期把 12V 直接送进额定 6V 电机。

若点击“前进”时一侧轮子方向反了，直接交换该电机接在 L298N 输出端的两根线。不要同时改两边，否则左右旋转逻辑会混乱。

## 使用

1. Arduino IDE 选择 `ESP32S3 Dev Module`，烧录 `esp32s3_l298n_2wd_caster_web_controller.ino`。
2. 手机连接热点 `ESP32_2WD_Caster`，密码 `motor1234`。
3. 访问 `http://192.168.4.1`。

默认 PWM 是 40%，可切换 20%、40%、60%、80%。网页关闭、手机断开热点或控制信号中断约 1.2 秒后，程序自动动态刹车。
